## 📌 About This Repository

**DSA-Learning-Hub** is a structured collection of Data Structures and Algorithms programs written in **C language**.

This repository contains my learning journey of DSA concepts, including searching, sorting, arrays, matrices, memory allocation, stack, queue, linked list, trees, and graphs.

The main goal of this repository is to build strong programming fundamentals and understand how different data structures work internally.

# ▶️ How to Run Programs

### 1. Clone Repository

```bash
git clone https://github.com/Jiyavishwanath1708/DSA-Learning-Hub.git
```

### 2. Open Folder

```bash
cd DSA-Learning-Hub
```

### 3. Compile C Program

Example:

```bash
gcc bubble_sort.c -o bubble_sort
```

### 4. Run Program

Windows:

```bash
bubble_sort.exe
```

Linux/Mac:

```bash
./bubble_sort
```
